# WK Global Visa

**Assessoria em vistos, passaportes e documentação internacional.**

Website institucional desenvolvido para apresentar os serviços da WK Global Visa e facilitar o contato com seus clientes.

[GitHub](https://github.com/pricilaoliveirarocha/wk-global-visa) · [Código-fonte](https://github.com/pricilaoliveirarocha/wk-global-visa/tree/main/src)

</div>

---

### 🌷 Sobre o projeto

Uma experiência web responsiva, com navegação intuitiva e informações organizadas para quem procura orientação em processos consulares.

### ✨ O que você encontra por aqui

- 🔎 Busca e catálogo de serviços de vistos
- 🛂 Informações sobre passaportes e documentação internacional
- 📋 Etapas do atendimento
- 🎥 Depoimentos em vídeo
- 💌 Contato por WhatsApp e e-mail

### 💻 Tecnologias

`Next.js` · `React` · `TypeScript` · `Bootstrap` · `CSS Modules` · `Lucide Icons`

### 🚀 Executando o projeto

```bash
git clone https://github.com/pricilaoliveirarocha/wk-global-visa.git
cd wk-global-visa
npm install
npm run dev
```

Acesse **http://localhost:3000**.
